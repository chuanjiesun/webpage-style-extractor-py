# Zleap 设计风格指南

本SKILL提取了 [Zleap](https://zleap.com/) 网站页面的完整设计风格，包含色彩系统、排版规范、组件样式和布局指南。

## 快速概览

- **行业**：科技 / 社交内容平台
- **设计风格**：极简现代
- **品牌主色**：`#FF8A00`（橙色）
- **字体**：系统默认无衬线（ui-sans-serif）
- **核心特点**：圆角UI、浅灰底色、橙色强调、细腻过渡

## 目录结构

```
zleap-design/
├── SKILL.md                   # 设计风格指南（核心文档）
├── README.md                  # 项目说明（本文件）
├── result_validation.html     # 验证页面
└── assets/                    # 提取数据
    ├── page-info.json         # 页面信息原始数据
    ├── extraction-summary.txt # 提取摘要
    └── page-screenshot.png    # 页面截图
```

## 使用方法

1. 打开 `SKILL.md` 查看完整的设计风格指南
2. 在浏览器中打开 `result_validation.html` 验证设计元素
3. 参考 `assets/page-info.json` 获取详细的组件样式数据
